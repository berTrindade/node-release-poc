# node-release-poc

Proof-of-concept demonstrating a complete Node.js release process: lint, test, CI, semantic versioning, changelog generation, release artifacts and GitHub Actions.

Quick start

1. Install dependencies:

```bash
npm ci
```

2. Run tests:

```bash
npm test
```

3. Lint:

```bash
npm run lint
```

4. Build a release tarball locally:

```bash
npm run build
# this will create a package tarball in ./dist
```

5. Create a release (locally):

Commit with Conventional Commit messages (see CONTRIBUTING.md), then:

```bash
npm run release
# standard-version will update package.json, CHANGELOG.md and create a git tag
```

Docker

Build image:

```bash
docker build -t node-release-poc:latest .
```

Run container:

```bash
docker run -p 3000:3000 node-release-poc:latest
```

Repository layout

- src/: application source
- tests/: unit tests (Jest + Supertest)
- .github/workflows/: CI and release workflows
- CHANGELOG.md: generated by standard-version
- RELEASE_PROCESS.md: release process documentation

See RELEASE_PROCESS.md for a step-by-step process and how this POC maps to the 8 core release concepts.
